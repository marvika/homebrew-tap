# marvika/tap

[Homebrew](https://brew.sh) casks for my Mac apps.

## Barn Owl

A tidier menu bar, and a Mac that stays awake when you need it to.
See [marvika/barnowl](https://github.com/marvika/barnowl).

```bash
brew install --cask marvika/tap/barn-owl
```

Update with `brew upgrade --cask barn-owl`. Uninstall with
`brew uninstall --cask barn-owl`, or add `--zap` to remove its settings too.
